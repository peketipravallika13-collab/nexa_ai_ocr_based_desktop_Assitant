# Nexa - AI OCR-Based Desktop Assistant

An intelligent desktop assistant powered by AI and OCR capabilities, built with PyQt6, EasyOCR, and custom extensible plugins.

## Features
- **OCR Engine**: Screen capturing, text extraction, and multi-modal document analysis.
- **AI Client Integration**: Multi-model support with streaming responses and assistant capabilities.
- **Plugin Architecture**: Modular extensible plugin system (Chart generator, Canva, Deep search, Email, File compression, Calculator, etc.).
- **Modern Desktop UI**: Interactive GUI built with PyQt6 with floating widgets, shortcuts, and background tray support.

## Installation

1. Clone repository:
```bash
git clone https://github.com/peketipravallika13-collab/nexa_ai_ocr_based_desktop_Assitant.git
cd nexa_ai_ocr_based_desktop_Assitant
```

2. Create virtual environment and install dependencies:
```bash
python -m venv venv
venv\Scripts\activate  # On Windows
pip install -r requirements.txt
```

3. Run the application:
```bash
python main.py
```
